# **App Name**: VoiceJournalAI

## Core Features:

- Recording Interface: Simple and intuitive recording interface with start/stop button and timer.
- Secure Audio Storage: Audio files are stored securely in Firebase Storage.
- Speech-to-Text Transcription: Tool to Transcribe the user's audio recording into text.
- AI-Powered Summarization: Tool to Generate a concise summary of the transcribed text, highlighting key topics and sentiments. 
- Entry Persistence: Store entries with date, audio URL, transcript, and summary in Firebase Firestore.
- Journal Entry List: List previous entries with date and summary preview.
- Journal Entry Playback and Review: Playback audio and review full text summary and transcription of a selected journal entry.

## Style Guidelines:

- Primary color: Deep sky blue (#00BFFF) for serenity and reflection.
- Background color: Light cyan (#E0FFFF), a very desaturated shade of blue, for a calm and unobtrusive backdrop.
- Accent color: Turquoise (#40E0D0) to highlight interactive elements.
- Body and headline font: 'PT Sans' (sans-serif) for modern readability.
- Use simple, outline-style icons for clarity.
- Subtle, fade-in animations for journal entry loading.
